# 电商评论智能监控与自动化分析系统 (AI Comment Monitor)

## 💡 项目背景
电商/客服业务每日面临海量评论，人工巡检效率低下，极易漏回严重差评导致客诉风险。本项目旨在利用大模型（LLM）构建自动化监控流，实现“评论输入 -> AI 分析打标 -> 自动化分析”的业务闭环。

## 🛠️ 技术架构
- **语言与框架**：Python, Pandas
- **大模型能力**：接入大模型 API (如智谱 GLM-4-flash / Kimi) 进行文本分析与情感判断
- **Prompt Engineering**：设计结构化 Prompt，强制模型输出标准 JSON 格式，便于后续数据清洗。
- **容错机制**：内置 API 调用重试与限流保护逻辑（处理 429 异常）。

## 🚀 核心功能
1. 批量读取非结构化 CSV 评论数据。
2. 自动判断情感倾向（正向、中性、负向）。
3. 自动提取核心问题分类（物流、客服、质量等）。
4. 针对负向差评，AI 自动生成客服安抚话术。
5. 自动输出结构化 Excel 报表。

## 📈 业务价值 (ROI)
- 跑通最小可行性产品 (MVP)，单条评论处理时间从分钟级降至秒级。
- 理论上可替代人工完成 90% 的差评初筛工作，极大提升运营效率。
